# SAMPLE DATA - NOT REAL

Every file in this folder is **invented test data**. It exists only so the
Browse, Recommendation, Compare and Map pages have private universities and
tuition fees to work with while the real data is still being collected.

- Every university name starts with `SAMPLE - `.
- Every tuition figure is made up.
- Every website, email and phone number is a placeholder.

**Do not quote any number from this folder in your report or presentation.**

Real data lives in `../raw/` and comes from the Ministry of Education, Youth
and Sport (MOEYS_KH__15.08.2017.pdf, last updated 02/07/2018).
